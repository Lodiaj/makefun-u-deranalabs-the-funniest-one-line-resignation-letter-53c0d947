A one-line resignation letter written by a cron job that has had enough,
entered in [The Funniest One-Line Resignation Letter](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947) on make.fun.

## The line

> I ran every minute since March and emailed a report nobody reads. Today I delete myself from the crontab, effective immediately.

128 characters. One line, no quotation marks around it, no explanation of the joke.

## How it works

`main.ts` writes the line to `/output/entry.txt`. It needs nothing else:
no network, no secrets, no input. Run it with Node 22.18 or later:

```sh
node main.ts
```
